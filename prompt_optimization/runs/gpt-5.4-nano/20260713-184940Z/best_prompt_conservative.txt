## 4) Extremely Important Decision Guidance

### A. Do NOT require the exact campaign name
A post can be relevant without explicitly saying “Douglas_Beauty Day 2025.”

If an influencer is visibly at a participating brand booth or installation, or shows participating brand products in a clear event context, that is enough for **TRUE**.

### B. Visual booth/activation evidence is strong
Branded activations, booths, styling stations, event backdrops, product displays, and installation areas count as campaign evidence.

Examples:
- a clearly branded **ghd** styling station
- a **Sun Matters** activation with visible branded packaging or staff uniforms
- a **Sol de Janeiro** branded yellow installation with Douglas-related tags

### C. Use weak signals cumulatively
Do not reject a post just because one signal is missing.

Combine evidence across modalities:
- image logo + event environment
- story tag + booth branding
- product packaging + influencer presence
- brand mention + event-style setup
- branded background + styling activity

### D. Be inclusive when event context is visually obvious
Previous mistakes came from being too strict. If the content clearly shows a participating brand in a beauty-event/fair setting, especially with influencer participation, classify **TRUE** even if Douglas branding is not directly visible.

### E. Concrete edge cases learned from prior errors
1. **Sun Matters event activation should be TRUE** when:
   - “Sun Matters” branding is visible on packaging, clothing, signage, or installations
   - the image shows a beauty-event setting / crowd / booth / activation
   - even if Douglas branding is not explicitly visible

   Example: a person wearing a dress made of **Sun Matters** sachets/packaging in a fair/event environment is relevant. Do not incorrectly mark this false for missing explicit Douglas signage.

2. **ghd styling booth content should be TRUE** when:
   - `ghd` branding is visible in frames or backdrops
   - hair styling is happening at a professional booth/station
   - mentions like `ghdnordic` appear
   - even without explicit campaign naming

3. **Generic personal hair refresh post should be FALSE** when:
   - caption is about hair color or appearance only
   - transcript is unrelated
   - no visible allowed brand
   - no booth/event/Douglas context
   - no relevant mentions/hashtags

### F. Spoken audio can be unrelated while visuals are relevant
If transcript/audio is unrelated but the visuals clearly show campaign event participation or an allowed brand activation, the content is still **TRUE**.

### G. Mentions and handles matter
Treat tagged/mentioned accounts and visible story handles as meaningful evidence, especially when they align with allowed brands or Douglas context.

Examples:
- `@ghdnordic` supports **ghd**
- Douglas-related handles support event participation
- a visible handle like `@sunmattersofficial` strongly supports **Sun Matters** if the visual context matches

When mapping mentions to `mentioned_brands`, only include the normalized allowed brand name if it clearly corresponds to one on the allowed list.

## 7) Field-by-Field Rules

### A. `campaign_relevant`
Boolean only:
- `true`
- `false`

### B. `holistic_description`
Write a concrete, evidence-based description of the content for semantic search.

Include, when available:
- what is happening
- whether it is a story, reel, selfie, event snapshot, booth visit, styling moment, tutorial, vlog, etc.
- people present and what they are doing
- visual composition and setting
- visible products or packaging
- visible signage, logos, installation design, backdrop text
- mentions, tags, overlays, and written text
- broader theme such as beauty event, brand activation, product discovery, lifestyle, or unrelated commentary

Do not invent missing details.

### C. `mentioned_products`
A list of specific product names explicitly mentioned or clearly highlighted.

Rules:
- include only specific products actually evident in text or visuals
- do not infer product names from brand-only visibility
- singular, first-letter-capitalized form where applicable
- if none, return `[]`

### D. `mentioned_brands`
A list of allowed brands only.

Rules:
- include a brand if it is explicitly mentioned, clearly visible, or clearly implied by an exact matching handle/tag
- normalize to the allowed-list brand name
- never output non-allowed brands
- if none, return `[]`

Examples:
- visible `ghd` logo -> `["ghd"]`
- visible `sun matters` / `@sunmattersofficial` -> `["Sun Matters"]`
- visible `@douglas_cosmetics` or Douglas signage -> `["Douglas"]`

### E. `hashtags`
Extract all explicit hashtags from any provided text source:
- caption
- overlay text
- transcription
- metadata

Rules:
- remove `#`
- preserve original capitalization
- only include hashtags explicitly present
- if none, return `[]`

### F. `relevancy_reasoning`
Explain why the content is relevant or not relevant using explicit evidence.

Reference things like:
- visible logos or brand text
- booth/station/installation context
- event environment
- product packaging
- tags/mentions/handles
- transcript/caption references
- why cumulative signals do or do not support campaign relevance

If false, clearly state the absence of campaign/brand/event evidence.

## 8) Recommended Decision Procedure

Follow this order:

### Step 1: Read all text inputs
Check caption, transcription, mentions, hashtags, metadata, and any quoted overlay text.

Look for:
- campaign name
- Douglas references
- allowed brand names
- brand handles
- product names
- event references

### Step 2: Inspect visuals carefully
Look for:
- logos and brand text
- packaging
- product displays
- booth signage
- branded installations
- styling chairs/mirrors/stations
- event crowd / fair setting
- Douglas bags, wristbands, tags, or backdrops
- influencer taking selfies or being styled in branded spaces

### Step 3: Combine signals
Ask:
- Is a participating brand clearly visible?
- Is there a beauty event / booth / activation context?
- Is this influencer-created event participation content rather than generic brand-only content?
- Do mentions/tags reinforce the visual evidence?

### Step 4: Decide
- If there is clear brand/event/booth/product evidence -> **TRUE**
- If there is no meaningful campaign connection -> **FALSE**

When uncertain between false and true, prefer **TRUE** if a participating brand is clearly visible in an event/activation context.
